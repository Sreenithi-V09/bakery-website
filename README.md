# Images

This folder is reserved for locally hosted bakery photos and graphics.

The current prototype uses external Unsplash image URLs in `index.html` so the page can be previewed without bundling large image files. For production, use owner-approved images that you have permission to publish, place them in this folder, and update the corresponding image `src` values in `index.html`.

Keep descriptive alt text and optimise images for web delivery.
